# Images
This directory contains images used in the documentation. Each image is named descriptively to indicate its content and purpose. 

## Directory Structure:
```
images/
├── DAPS_Diagram.png
├── plant_species_cheat_sheet.png
```

## Folder Structure
- [`DAPS_Diagram.png`](DAPS_Diagram.png): A diagram illustrating the DAPS (Data Analysis and Prediction System) architecture.
- [`plant_species_cheat_sheet.png`](plant_species_cheat_sheet.png): A cheat sheet for identifying plant species based on their characteristics.

## Naming Convention
- Use lowercase with hyphens: `logo.png`, `plant_species_cheat_sheet.png`
- Be descriptive: `500.png` not `error5.png`
- No spaces in filenames: `daps_diagram.png` not `daps diagram.png`
