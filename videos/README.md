# Videos Directory
This directory contains videos related to the project, such as demonstrations of the plant identification tool, tutorials on how to use the application, and any relevant video content that supports the documentation and development of the project.

## Directory Structure:
```
videos/
├── Demo_BotaniScan_User.mp4
└── Promo_BotaniScan.mp4
```

## Folder Structure
- [`Demo_BotaniScan_User.mp4`](Demo_BotaniScan_User.mp4): A demonstration video showing how a user interacts with the BotaniScan application to identify an indoor plant.
- [`Promo_BotaniScan.mp4`](Promo_BotaniScan.mp4): A promotional video highlighting the features and benefits of the BotaniScan tool for both businesses and consumers.
