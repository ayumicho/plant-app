# Iterations
This directory contains the Jupyter notebooks for each iteration of the project. Each notebook corresponds to a specific iteration and includes the tasks completed during that iteration. The notebooks are organized as follows:

```
iterations/
├── iteration_1.ipynb
├── iteration_2.ipynb
├── iteration_3.ipynb
└── iteration_4.ipynb
```
## Notebook Structure
Each notebook is structured to reflect the tasks completed during that iteration. The sections typically include:
- **Preprocessing**: Details the data preprocessing steps taken, such as data cleaning, augmentation, and normalization.
- **Model Architecture**: Describes the architecture of the model used in that iteration, including layer types, activation functions, and any modifications made from previous iterations.
- **Model Performance**: Presents the performance metrics of the model, such as accuracy, loss  curves, and confusion matrices.
- **Error Analysis**: Analyzes the errors made by the model, identifying common misclassifications and potential reasons for them.
- **MLP From Scratch**: For iterations that include building a Multilayer Perceptron from scratch, this section details the implementation and results of that model.

## Usage
To run any of the notebooks, simply open it in Jupyter Notebook or JupyterLab and execute the cells sequentially. Each notebook is self-contained and includes all necessary code and explanations for the tasks completed in that iteration.

## Naming Convention
- Use lowercase with underscores: `iteration_1.ipynb`, `iteration_2.ipynb`
- Be descriptive: `iteration_1.ipynb` not `iter1.ipynb`
- No spaces in filenames: `iteration_1.ipynb` not `iteration 1.ipynb`
