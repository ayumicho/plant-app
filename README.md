# BotaniScan: Plant Identification Tool

## Project Overview

This project, developed as part of the Year 1 project in the first half of the second semester (Block C), focuses on creating an image classifier specifically designed for the indoor plant market. The goal is to provide a user-friendly tool for identifying indoor plants, helping both businesses (plant shops) and consumers make informed decisions regarding plant care and purchasing.

## Problem Statement

The indoor plant market is booming, but many consumers struggle with identifying species and understanding specific care requirements. For organizations, this leads to high pressure on customer service and missed sales opportunities. **BotaniScan** alleviates these issues by providing instant, scientifically accurate plant classification.

## Repository Structure

The original comprehensive notebook has been split into task-specific files for better modularity and clarity:

* **`docs/`**: Contains baseline model performance (task 3.1), business understanding documentation (task 1), and other project-related documentation.
* **`images/`**: Contains images used in the documentation, such as the DAPS diagram and plant species cheat sheet.
* **`iterations/`**: Contains Jupyter notebooks for each iteration of the project, detailing preprocessing, model architecture, performance, and error analysis (tasks 3.2 to 3.7).
* **`notebooks/`**: Contains basic MLP implementation (task 3.1) and data preparation steps (task 2.1).
* **`videos/`**: Contains demonstration and promotional videos related to the project.

## Key Stakeholders

* **Botanical Research Centers:** Require scientific accuracy and rarity status features.
* **Plant Shops:** Need a fast, simple interface for inventory management and customer support.
* **Consumers/Hobbyists:** Focused on ease of use, mobile accessibility, and care tips.
* **IT Departments:** Concerned with scalability, documentation, and integration.

## Project Goals
1. **Accurate Classification:** Achieve high accuracy in identifying indoor plant species.
2. **User-Friendly Interface:** Develop an intuitive interface for both businesses and consumers.

### Methodology
The project follows a structured approach, starting with business understanding and baseline model development, followed by iterative improvements in preprocessing, model architecture, and performance evaluation. Each iteration builds upon the previous one, incorporating insights from error analysis to refine the model.   


## Product
The final product will be a web-based application that allows users to upload images of indoor plants and receive instant identification along with care tips. The application will be designed with a focus on user experience, ensuring it is accessible to both plant shops and consumers.

Due to the scope of this project, the application will be developed as a prototype, with potential for future expansion based on user feedback and additional features such as rarity status and care recommendations.
